# 🚀 Classroom Tool Workshop

A follow-along guide that takes teachers from zero to a **live, GitHub-hosted classroom tool** — using only a web browser and **Gemini**. No terminal, no installs.

**▶ Open it:** https://tdavidsm.github.io/classroom-tool-workshop/

## What it covers
- Creating a free **GitHub** account and understanding the three pieces (GitHub, one `index.html` file, Gemini).
- A working **Random Student Picker** to copy as-is (or a starter prompt to build your own with Gemini).
- Seven click-by-click steps: new repository → add `index.html` → turn on **GitHub Pages** (`main` / root) → visit your live URL.
- Customizing with Gemini, troubleshooting (404s, caching, first-build timing), and the repeatable **Ask → Paste → Commit → Refresh** loop.

Meta note: this page was itself built and shipped with the exact process it teaches.

## Tech
Single self-contained `index.html` — plain HTML/CSS/JS, no dependencies, light/dark aware, touch-friendly for iPad. Deployed via GitHub Pages from `main`.
